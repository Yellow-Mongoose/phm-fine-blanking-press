# TrainValid분석_v4_2 (공백 무시, 행 단위 분할)

**시간순 행 위치**로 분할하고(정상 70%·80% 지점, 이상 앞 200행 / 뒤 400행), 각 분할 안에서 끊김을 넘어 윈도를 이어 붙입니다. 라벨은 윈도 마지막 행입니다.

| 파일 | 내용 |
|---|---|
| `요약.md` | **분석 결과 요약.** VS Code에서 열고 `Ctrl+Shift+V`를 누르세요 |
| `KAMP_TrainValid분석_v4_2.ipynb` | 분석 노트북. 위에서부터 모두 실행하면 결과와 요약이 새로 만들어집니다 |
| `결과/<실행시각>/` | 그래프, CSV, `frozen_pipeline.json`(후보 점수와 임계값), `split_manifest.csv`(원본 행마다 분할), `summary_metrics.json`(비교용 숫자), 그 실행의 `요약.md` 사본 |

## 원칙

- 이 노트북은 **Train과 Valid만** 씁니다. Test는 분할 직후 따로 떼어 두고 분석과 평가에 쓰지 않습니다.
- 학습(표준화, PCA, 공분산, VIF)은 정상 Train으로, 선택(변수, 임계값)은 Valid로 합니다.
- v4_1, v4_2, v4_3은 서로 독립된 분석입니다. 폴더끼리 변수나 임계값을 주고받지 않습니다.
- **공식 분할은 나중에 하나만 정합니다.** 모델을 최종 비교하기 전에 세 폴더 중 하나의 `split_manifest.csv`를 공식 분할로 정하고, 모든 모델이 그 분할만 씁니다.

세 폴더의 비교는 상위 폴더의 `reports/v4_비교.md`에 있고, 처리 규칙의 근거는 `reports/데이터처리_판단근거.md`에 있습니다.
