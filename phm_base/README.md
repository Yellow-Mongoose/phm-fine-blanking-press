# PHM Base — 프레스 전류·진동 센서 이상 탐지 실험

센서 데이터로 여러 모델을 학습하고 성능을 비교하는 프로젝트입니다.
**처음이라면 [01 기본 학습 노트북](notebooks/main/01_baseline_lstm_raw.ipynb) 하나부터 실행하세요.** 모든 파일을 실행할 필요는 없습니다.

## 1. 처음 실행하는 방법

1. `press_data_normal.csv`, `outlier_data.csv`를 준비합니다. 데이터는 별도로 준비해야 합니다.
2. 위 노트북을 **Jupyter·VS Code 또는 Colab**에서 엽니다. `.ipynb`는 설명과 코드를 위에서부터 실행하는 파일입니다.
3. 첫 코드 셀에서 실행 방법을 설정합니다.
   - **로컬:** `DATA_MODE='folder'`, `DATA_ROOT`에 CSV 두 개가 있는 폴더 지정
   - **Colab:** GPU 런타임 선택 후 `DATA_MODE='upload'`로 파일 업로드. Drive를 쓰려면 `'drive'` 선택
   - **W&B를 사용하지 않을 때:** `WANDB_ENABLED=False`로 변경. W&B는 실험 결과를 웹에 기록하는 서비스입니다.
4. 위에서부터 셀을 실행합니다. 필요한 입력·인증은 앞부분에서 안내하며 결과 표와 그래프는 노트북 안에 표시됩니다.

누락 패키지는 `INSTALL_MISSING=True`로 설치한 뒤 커널을 재시작합니다. 기본 학습은 PyTorch, G00은 TensorFlow 실행 환경이 필요합니다. GPU 없이 실행하려면 `DEVICE_REQUEST='cpu'`로 지정합니다.

**기본 설정은 점검 후 본학습과 Test 평가까지 실행합니다.** 2 epoch 점검만 하려면 `RUN_TRAINING=False`, `RUN_TEST=False`로 바꾸세요. 튜닝 노트북에서는 `RUN_HPO=False`도 필요합니다. 점검 결과는 파일·W&B에 저장하지 않습니다.

## 2. 어떤 파일을 사용하나요?

| 파일·폴더 | 쉬운 설명 | 사용 시점 |
|---|---|---|
| [main/](notebooks/main/) | 기본 모델 학습과 평가 | 여기서 시작 |
| [reference/](notebooks/reference/) | 가이드북 방식의 참고 실험 G00 | 기본 비교 뒤, 추가 실험 전 |
| [tuning/](notebooks/tuning/) | 모델의 학습 설정을 자동으로 탐색하는 HPO | 기본 실험 확인 후 선택 |
| [additional/](notebooks/additional/) | 정규화·입력 특징 등을 바꾸는 추가 실험 | 필요한 경우 선택 |

기본 비교 순서는 **01 → 02 → 18 → 19 → 04 → 06 → 08**을 권장합니다. 각 학습 노트북은 별도 프로젝트 `.py` 파일 없이 실행됩니다. 학습 노트북 27개를 포함하며, 각 노트북 안에서 평가 결과와 그래프를 확인할 수 있습니다.

## 3. 결과는 어디에 있나요?

- **로컬:** 첫 설정 셀의 `OUTPUT_ROOT`에 원하는 결과 폴더를 지정하세요. 미지정 시 현재 노트북이 속한 프로젝트의 `results/`를 사용합니다. 프로젝트를 찾지 못하는 환경에서는 현재 작업 폴더의 `results/`를 사용하며 실제 경로는 실행 시 표시됩니다.
- **Colab:** `drive` 모드는 Drive에 백업합니다. 임시 저장소를 쓰면 런타임 종료 전에 결과 ZIP을 다운로드하세요.
- **저장 내용:** 학습 지표, 최종 곡선, epoch가 표시된 가중치, 평가·분석 결과. HPO는 정상 완료 후 최종 선정 후보의 가중치와 epoch별 전체 Valid 점수만 남기고 다른 후보의 요약 기록은 유지합니다.

모델 선택은 **Valid(검증 데이터)**로 하고 **Test(최종 평가 데이터)** 결과로 튜닝하지 않습니다. G00은 데이터 처리·평가 조건이 달라 일반 실험과 같은 조건의 순위로 합치지 않습니다. 현재와 10초 뒤 라벨이 계속 같다면 높은 성능만으로 사전 예측 능력을 입증할 수 없습니다.

GitHub에는 코드와 안내만 공유합니다. 데이터·결과·인증 파일은 `.gitignore`로 제외하며, **실행 출력을 공유할 때는 개인 계정·인증 정보·로컬 경로가 없는지 확인하세요.** 웹에서 직접 업로드할 때는 `.gitignore`가 자동 적용되지 않습니다.

01·02에는 개인정보를 가린 기존 실행 결과를 포함했습니다. 01은 학습·Test 결과, 02는 학습 중단 전까지의 결과이며 현재 코드로 재실행한 결과는 아닙니다.
